# Product

## Register
product (app) with a short brand landing.

## Users
Spanish-speaking people, mobile-first (commute, evening, one-handed), also desktop. They hold a YouTube link and want the substance without watching.

## Product purpose
TubeRezume: paste a YouTube link, backend fetches the transcript and summarizes it, results persist in the user's library (backend exists elsewhere; this repo is frontend only, mocked API layer).

## Brand / tone
Modern, luminous, disruptive. Reference: reactbits backgrounds (ghost-fibers, laser-flow, web-threads, strands, lightfall, plasma-wave, electric-logo, soft-aurora, antigravity, crystalized-ball). Re-implemented originally, not copied.

## Stack (fixed)
TypeScript, Tailwind v4, pnpm, GSAP, shadcn where useful, original canvas/WebGL effects.

## Anti-references
Default AI-purple SaaS, three equal cards, generic YouTube-red clone.

## Constraints
Dark default + light theme. UI in Spanish. prefers-reduced-motion respected. Performance on mid phones.
